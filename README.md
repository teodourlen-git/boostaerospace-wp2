# BoostAeroSpace — Budget WP2 2027 (version web)

Site statique, sans build : `index.html` + `deck.css` + `assets/` (2 vidéos MP4 et leurs vignettes).

## Navigation
- Flèches du clavier, espace ou clic : slide suivante / précédente (clic sur le tiers gauche = retour)
- Glisser à gauche / à droite sur mobile
- `F` ou bouton « Plein écran »
- Chaque slide a son adresse : `#1`, `#2`…
- Les vidéos Petzl et Camden démarrent à l'arrivée sur leur slide, avec le son dès qu'on a navigué une fois

## Déploiement Netlify
Dossier à publier : la racine de ce dossier (aucune commande de build).
La page porte une balise `noindex` pour ne pas être référencée par les moteurs de recherche.
